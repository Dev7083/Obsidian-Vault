###  Variables (Storing Data)

A variable stores a value.
```
let age = 21;  
let name = "Devendra";
```
👉 Think: **container for data**

---

### Data Types

Common types:
- Number → `10, 3.14`
- String → `"hello"`
- Boolean → `true / false`
- Array → `[1,2,3]`
- Object → `{name: "Dev"}`

---

### Conditional Statements (Decision Making)

```
if (age >= 18) {  
  console.log("Adult");  
} else {  
  console.log("Minor");  
}
```
👉 Used when program needs to **decide**

---
###  Loops (Repetition)

```
for (let i = 0; i < 5; i++) {  
  console.log(i);  
}
```
👉 Repeat tasks automatically

---

### Functions (Reusable Code)

```
function greet(name) {  
  return "Hello " + name;  
}
```
👉 Write once, use many times

---
###  Input & Output

- Input → user data
- Output → result
console.log("Hello World");
---
###   Operators

- Arithmetic → `+ - * / %`
- Comparison → `== === > <`
- Logical → `&& || !`
---
###  Arrays & Objects

```
let arr = [1,2,3];  
let user = { name: "Dev", age: 21 };
```

- Used to store **multiple values**

---
###  Errors & Debugging

- Syntax error → wrong code format
- Runtime error → error while running
- Use logs  to debug
---
###  Basic Flow (Very Important)

Every program follows:
👉 **Input → Process → Output**
